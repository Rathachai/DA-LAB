How it works

  1. Window: turn the series into a table — each row holds the last w values (x₁…xw) and the value that follows (y).
  2. Split: keep some rows aside as a test set. For time series, a chronological split (train on the past, test on the future) mimics real forecasting; a random split lets the model "peek" at the future.
  3. Fit: a linear model y = β₀ + β₁x₁ + … + βwxw is an autoregressive model — it predicts from its own past.
  4. Predict: the red solid line (train) and red dashed line (test) are its predictions: on train rows each uses real past values (one step ahead). In a chronological split the test line is built from the model's own earlier predictions (multi-step), so errors can pile up.

Try: a noisy sine with w = 1 vs. w = 10; a random walk (hard to beat the naive baseline); then drag a bump into the test period and see how the error reacts.
