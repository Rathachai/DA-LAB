Look for the highest Adj. R² with the fewest features. Compare Test MAE / MAPE with the train values across feature sets and split ratios. x3 and x4 are noise — they tend to look fine on train rows but not on test rows, especially when the train set is small (try 10–30 %).

Feature-selection checklist

  • Keep features with a strong |r| with y (positive or negative).
  • Drop features with r ≈ 0 — they add noise, not signal.
  • If the graph is curved (e.g. exponential), try the log transform — a straighter cloud means a higher |r| and a better linear fit.
  • A U-shape (like x3) has r ≈ 0 but still depends on y: a straight line cannot capture it, so r alone can mislead.
  • Never use y itself (data leakage) or an id (meaningless number).
  • Judge each model on the test rows (Test RMSE / Test R²), not on the rows it trained on.
  • With a small train ratio the fit is unstable — hit Random split again a few times to see how much results move.
