Checklist for RUL models

  • Keep sensors with a strong |r| with RUL (positive or negative).
  • rpm is pure noise: r ≈ 0 and no extra information once the others are in.
  • Pressure has a U-shape: r ≈ 0 yet it depends on RUL — a straight line cannot capture it.
  • Wear debris grows exponentially as the machine ages: tick log to straighten it.
  • Never use y (leakage) or id/machine (meaningless numbers) as features.
  • Snapshots from one machine are not independent. Split by machine, so the test set simulates new machines.
