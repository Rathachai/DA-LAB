How it works

  1. Each machine has a hidden actual RUL r (hours to failure). The model predicts p = r·(1+bias) + σ·noise.
  2. Rule: repair now if p ≤ H. Otherwise the machine runs until the next inspection D hours later and breaks down if r < D.
  3. Repair costs Cp + Cw·r (the unused life r is thrown away). A breakdown costs Cf. Correctly leaving a healthy machine running costs nothing.
  4. Error metrics (MAE, RMSE...) ignore which direction the error goes. Costs do not: when Cf ≫ Cp, under-estimating life (pessimism) is cheap and over-estimating it is expensive.
  5. Moving H is the same as adding a safety margin. A pessimistic bias acts the same way, which is why a model with a larger error can still make cheaper decisions.
