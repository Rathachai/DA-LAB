Why split the data?

A model always looks good on the points it was trained on. To know whether it works on new data, we keep some points aside (the test set) and never train on them.

  • Small train % → few points to learn from → the line is unstable and changes a lot with each random split.
  • Small test % → few points to judge with → the test score is noisy and may be lucky or unlucky.
  • Common choices: 70/30, 80/20.

Split experiment how much does the random split matter?

Each run: shuffle the data → fit the best line on the train part → measure RMSE on the test part. Repeat 50 times at the current ratio, then try 10 %, 50 %, 90 % and compare how much the test RMSE varies.

How gradient descent works

Think of MSE as a bowl-shaped hill over (m, c). Each step walks a little downhill:

  1. Predict: ŷ = m·x + c
  2. Measure loss: MSE = mean((y − ŷ)²)
  3. Find the slope of the hill: ∂m = −2·mean(x·(y−ŷ)), ∂c = −2·mean(y−ŷ)
  4. Step downhill: m ← m − α·∂m, c ← c − α·∂c

Too small α → slow. Too large α → overshoots and diverges. Try it!
